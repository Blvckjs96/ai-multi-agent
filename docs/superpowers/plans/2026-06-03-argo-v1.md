# Argo v1.0 — Master Blueprint

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Scope note:** This master blueprint covers 6 independent phases. Phase 0 is written with full bite-sized tasks. Phases 1–6 are written at task level — each phase MUST be expanded into its own detailed plan (`docs/superpowers/plans/2026-06-03-argo-v1-phase-N.md`) before implementation begins.

**Goal:** Transform Argo from a partially-wired desktop tool into a unified, production-grade personal AI workspace — with OWU as design blueprint, Claude CLI + git worktrees + IssueBoard + CodeGraph as core differentiators, and every feature fully wired end-to-end.

**Architecture:** React + Vite + Tauri 2 desktop, FastAPI + PostgreSQL backend, Tailwind CSS replacing raw CSS vars, Zustand for global state. OWU's pattern language (access_control, group permissions, workspace panels, settings tabs) is ported and adapted — no dependency on OWU at runtime. All new backend routes follow Argo's Routes → Services → Repositories pattern.

**Tech Stack:**
- Frontend: React 18, Vite, Tauri 2, **Tailwind CSS v4**, **Zustand**, `react-markdown`, `rehype-highlight`, `rehype-katex`, `remark-gfm`, Monaco Editor (tools/code editor)
- Backend: FastAPI, SQLAlchemy async, asyncpg, PostgreSQL, Redis, Alembic, Pydantic v2
- New backend services: `permissions.py`, `notes.py`, `automations.py`, `analytics.py`, `evaluations.py`, `audio.py`, `web_search.py`
- Test: pytest + httpx.AsyncClient (backend), existing patterns

## Architecture Decisions (Locked In)

These decisions are final and must not be revisited per phase:

### D1 — Tailwind replaces raw CSS (Phase 0)
Install Tailwind v4 into the existing Vite project. Migrate CSS variables to Tailwind theme tokens. All new components use Tailwind classes. Existing components migrate opportunistically — do not block features waiting for full CSS migration.

### D2 — Zustand replaces local useState for shared state (Phase 0)
One global store `src/store/index.js` mirrors OWU's `stores/index.ts`. All cross-panel state (user, models, conversations, knowledge, theme, socket) lives here. Component-local state (hover, open/close) stays local.

### D3 — OWU's access_control pattern for permissions (Phase 0)
`backend/app/core/permissions.py` — nested dict permissions, group-based, `has_permission(user_id, "chat.file_upload")`. Replaces `RoleChecker(ADMIN)`. New roles: `pending | user | admin`.

### D4 — Common UI component library built first (Phase 0)
`frontend/src/components/ui/` — Modal, Drawer, Dropdown, ConfirmDialog, CodeEditor, Badge, Pagination, FileItem. All features in Phase 1–6 use this library. Nothing ships that creates its own modal from scratch.

### D5 — Argo differentiators are non-negotiable (all phases)
IdeLayout, IssueWorkspace, TerminalTab, CodeGraph, git worktrees, Claude CLI plan/confirm, argomemory STM/LTM — these are the product. No phase may remove or downgrade them.

### D6 — No OWU runtime dependency
Everything is ported/reimplemented in React + FastAPI. OWU is used as a design reference only.

### D7 — Feature flags for enterprise features
LDAP, SCIM 2.0, image generation are behind `settings.FEATURE_*` flags. Disabled by default. This prevents scope creep in early phases.

```jsx
// frontend/src/components/ui/Modal.jsx
import { useEffect, useRef } from 'react'
import { createPortal } from 'react-dom'
import { X } from 'lucide-react'

/**
 * @param {{ open: boolean, onClose: () => void, title?: string,
 *           size?: 'sm'|'md'|'lg'|'xl', children: React.ReactNode }} props
 */
export default function Modal({ open, onClose, title, size = 'md', children }) {
  const overlayRef = useRef(null)

  useEffect(() => {
    if (!open) return
    const handler = (e) => { if (e.key === 'Escape') onClose() }
    window.addEventListener('keydown', handler)
    return () => window.removeEventListener('keydown', handler)
  }, [open, onClose])

  if (!open) return null

  const widths = { sm: 'max-w-sm', md: 'max-w-lg', lg: 'max-w-2xl', xl: 'max-w-4xl' }

  const handleOverlayClick = (e) => {
    if (e.target === overlayRef.current) onClose()
  }

  return createPortal(
    <div
      ref={overlayRef}
      className="fixed inset-0 z-50 flex items-center justify-center bg-black/60 backdrop-blur-sm"
      onClick={handleOverlayClick}
      role="dialog"
      aria-modal="true"
    >
      <div
        className={`relative flex flex-col w-full ${widths[size]} mx-4 rounded-xl border border-argo-border bg-argo-surface shadow-2xl`}
        style={{ animation: 'scale-in 160ms var(--ease-out) both' }}
      >
        {(title || true) && (
          <div className="flex items-center justify-between px-5 py-4 border-b border-argo-border">
            {title && (
              <h2 className="text-sm font-semibold text-argo-primary">{title}</h2>
            )}
            <button
              type="button"
              onClick={onClose}
              className="ml-auto flex items-center justify-center w-7 h-7 rounded-lg text-argo-muted hover:text-argo-primary hover:bg-argo-elevated transition-colors"
              aria-label="Close"
            >
              <X size={14} />
            </button>
          </div>
        )}
        <div className="flex-1 overflow-y-auto">
          {children}
        </div>
      </div>
    </div>,
    document.body
  )
}
```

// frontend/src/components/ui/Dropdown.jsx
import { useEffect, useRef, useState } from 'react'

/**
 * @param {{
 *   trigger: React.ReactNode,
 *   items: Array<{ label: string, icon?: React.ReactNode, onClick: () => void, danger?: boolean }>,
 *   align?: 'left'|'right',
 *   className?: string
 * }} props
 */
export default function Dropdown({ trigger, items, align = 'left', className = '' }) {
  const [open, setOpen] = useState(false)
  const ref = useRef(null)

  useEffect(() => {
    const handler = (e) => {
      if (ref.current && !ref.current.contains(e.target)) setOpen(false)
    }
    document.addEventListener('mousedown', handler)
    return () => document.removeEventListener('mousedown', handler)
  }, [])

  return (
    <div ref={ref} className={`relative ${className}`}>
      <div onClick={() => setOpen((o) => !o)}>{trigger}</div>
      {open && (
        <div
          className={`absolute z-40 mt-1 min-w-[160px] rounded-lg border border-argo-border bg-argo-surface shadow-xl py-1
            ${align === 'right' ? 'right-0' : 'left-0'}`}
          style={{ animation: 'fade-up 120ms var(--ease-out) both' }}
        >
          {items.map((item, i) => (
            <button
              key={i}
              type="button"
              onClick={() => { item.onClick(); setOpen(false) }}
              className={`flex items-center gap-2 w-full px-3 py-2 text-left text-xs font-medium transition-colors
                ${item.danger
                  ? 'text-argo-error hover:bg-red-500/10'
                  : 'text-argo-secondary hover:bg-argo-elevated hover:text-argo-primary'
                }`}
            >
              {item.icon && <span className="flex-shrink-0 opacity-70">{item.icon}</span>}
              {item.label}
            </button>
          ))}
        </div>
      )}
    </div>
  )
}
```

# backend/app/core/permissions.py
"""Permission utilities — ported from OWU access_control pattern."""
from __future__ import annotations

import json
from typing import Any

from sqlalchemy.ext.asyncio import AsyncSession

DEFAULT_USER_PERMISSIONS: dict[str, Any] = {
    "chat": {
        "file_upload": True,
        "delete": True,
        "edit": True,
        "temporary": True,
        "voice_input": True,
    },
    "workspace": {
        "models":    {"create": False, "update": False, "delete": False, "share": False},
        "knowledge": {"create": True,  "update": True,  "delete": True,  "share": False},
        "tools":     {"create": False, "update": False, "delete": False, "share": False},
        "skills":    {"create": True,  "update": True,  "delete": True,  "share": False},
        "prompts":   {"create": True,  "update": True,  "delete": True,  "share": False},
    },
    "terminal": {"execute": True},
    "artifacts": {"read": True, "write": True},
}


def fill_missing_permissions(
    permissions: dict[str, Any],
    default_permissions: dict[str, Any],
) -> dict[str, Any]:
    """Recursively fill in missing keys from defaults."""
    for key, value in default_permissions.items():
        if key not in permissions:
            permissions[key] = value
        elif isinstance(value, dict) and isinstance(permissions[key], dict):
            permissions[key] = fill_missing_permissions(permissions[key], value)
    return permissions


def _combine(a: dict[str, Any], b: dict[str, Any]) -> dict[str, Any]:
    """Merge two permission dicts taking the most permissive value (True > False)."""
    for key, value in b.items():
        if isinstance(value, dict):
            a[key] = _combine(a.get(key, {}), value)
        else:
            a[key] = a.get(key, value) or value
    return a


def has_permission_sync(
    permissions: dict[str, Any],
    permission_key: str,
) -> bool:
    """Check a dotted permission key against a permissions dict. Returns False if missing."""
    keys = permission_key.split(".")
    node: Any = permissions
    for k in keys:
        if not isinstance(node, dict) or k not in node:
            return False
        node = node[k]
    return bool(node)


async def get_user_permissions(
    user_id: str,
    db: AsyncSession,
) -> dict[str, Any]:
    """Return merged permissions for a user from all their groups."""
    from app.repositories.group import get_groups_by_member_id  # late import

    groups = await get_groups_by_member_id(db, user_id)
    permissions = json.loads(json.dumps(DEFAULT_USER_PERMISSIONS))
    for group in groups:
        if group.permissions:
            permissions = _combine(permissions, group.permissions)
    return permissions


async def has_permission(
    user_id: str,
    permission_key: str,
    db: AsyncSession,
) -> bool:
    """Async check: get user's merged permissions and evaluate a dotted key."""
    permissions = await get_user_permissions(user_id, db)
    return has_permission_sync(permissions, permission_key)
```

from __future__ import annotations
from typing import Any
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession
from app.db.models.group import Group


async def create_group(
    db: AsyncSession,
    *,
    name: str,
    description: str | None = None,
    permissions: dict[str, Any] | None = None,
) -> Group:
    group = Group(name=name, description=description, permissions=permissions or {})
    db.add(group)
    await db.flush()
    await db.refresh(group)
    return group


async def get_groups_by_member_id(db: AsyncSession, user_id: str) -> list[Group]:
    result = await db.execute(
        select(Group).where(Group.member_ids.contains([user_id]))
    )
    return list(result.scalars().all())


async def add_member(db: AsyncSession, group_id: str, user_id: str) -> Group | None:
    result = await db.execute(select(Group).where(Group.id == group_id))
    group = result.scalar_one_or_none()
    if not group:
        return None
    if user_id not in group.member_ids:
        group.member_ids = [*group.member_ids, user_id]
    await db.flush()
    await db.refresh(group)
    return group


async def remove_member(db: AsyncSession, group_id: str, user_id: str) -> Group | None:
    result = await db.execute(select(Group).where(Group.id == group_id))
    group = result.scalar_one_or_none()
    if not group:
        return None
    group.member_ids = [uid for uid in group.member_ids if uid != user_id]
    await db.flush()
    await db.refresh(group)
    return group

C — Icon Rail + Chat History + Pipeline Bar

Icon rail cố định + chat history sidebar riêng (như VS Code). Pipeline hiển thị như status bar trên đầu chat. Chat là trung tâm, pipeline là context.

Tất cả phương án đều có:

  • Side nav có thể collapse/expand (thay thế horizontal tab bar hiện tại)
  • Chat history với CRUD (new, rename, delete conversations)
  • Pipeline tích hợp vào trong chat flow (không phải tab riêng)
  • Nút "+" rõ ràng hơn trong Issues tab để thêm repo folder
  • File attachment trong chat input
